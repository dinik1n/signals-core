# Signal Processing Core

`SignalProcessing.Core` — библиотека на C# для генерации, хранения и обработки одноканальных цифровых сигналов. Библиотека предоставляет инструменты для фильтрации, выполнения операций над сигналами, изменения частоты дискретизации, анализа диапазонов и обнаружения пересечений заданного порога.

Библиотека не зависит от графического интерфейса и может использоваться независимо от приложения.

## Основные возможности

- Создание и хранение одноканальных сигналов.
- Генерация сигналов различных форм.
- Фильтрация сигналов офлайн и в потоковом режиме.
- Выполнение операций сложения и объединения сигналов.
- Изменение частоты дискретизации.
- Чтение и запись сигналов в файлы.
- Анализ диапазонов значений.
- Обнаружение пересечений заданного порога.
- Получение уведомлений о событиях через механизм подписки.

## Структура решения

Решение состоит из двух проектов:

| Проект | Назначение |
|---|---|
| `SignalProcessing.Core` | Основная библиотека обработки сигналов |
| `SignalProcessing.Core.Tests` | Модульные тесты библиотеки на xUnit |

**Целевая платформа:** .NET Framework 4.8.

Библиотека собирается самостоятельно, без необходимости запуска графического приложения.

## Работа с сигналами

| Класс | Назначение |
|---|---|
| `SingleChannelSignal` | Представляет одноканальный сигнал, содержащий массив отсчётов и частоту дискретизации |
| `SingleChannelSignalReader` | Читает сигнал из файла |
| `SingleChannelSignalWriter` | Записывает сигнал в файл |
| `SignalOperations` | Выполняет операции над сигналами: сложение и объединение |
| `Resampler` | Изменяет частоту дискретизации сигнала |
| `SingleChannelRangeAnalyzer` | Выполняет анализ диапазона значений сигнала |

## Генерация сигналов

Для унификации генерации используется интерфейс `ISignalGenerator`. Он определяет общий способ создания сигнала на основе параметров дискретизации.

Основные классы:

| Класс | Назначение |
|---|---|
| `ISignalGenerator` | Общий интерфейс генераторов |
| `SamplingParameters` | Содержит параметры дискретизации: частоту, длительность и количество отсчётов |
| `GeneratorParameters` | Базовый тип параметров генерации |
| `SineParameters` | Параметры синусоидального сигнала |
| `LineParameters` | Параметры линейного сигнала |
| `NoiseParameters` | Параметры шумового сигнала |
| `TriangleParameters` | Параметры треугольного сигнала |
| `SawParameters` | Параметры пилообразного сигнала |
| `ConstantParameters` | Параметры постоянного сигнала |
| `SineGenerator` | Генерирует синусоидальный сигнал |
| `LineGenerator` | Генерирует линейный сигнал |
| `NoiseGenerator` | Генерирует шумовой сигнал |
| `TriangleGenerator` | Генерирует треугольный сигнал |
| `SawGenerator` | Генерирует пилообразный сигнал |
| `ConstantGenerator` | Генерирует постоянный сигнал |
| `SignalGeneratorFactory` | Создаёт генераторы в соответствии с выбранным типом сигнала |

## Фильтрация сигналов

Библиотека поддерживает несколько способов фильтрации.

| Класс | Назначение |
|---|---|
| `OfflineFilter` | Скользящее среднее для обработки всего массива данных |
| `OnlineFilter` | Скользящее среднее для последовательной обработки данных |
| `OfflineMedianFilter` | Медианная фильтрация всего сигнала |
| `OnlineMedianFilter` | Медианная фильтрация поступающих данных |
| `ExponentialSmoothingFilter` | Экспоненциальное сглаживание сигнала |

Потоковые фильтры поддерживают сброс внутреннего состояния с помощью метода `Reset()`.

## Анализ пересечений порога

Для обнаружения пересечений заданного уровня используется `ThresholdAnalyzer`.

Анализатор проверяет соседние отсчёты сигнала и определяет моменты пересечения порога в двух направлениях:

- `CrossingDirection.Up` — пересечение снизу вверх.
- `CrossingDirection.Down` — пересечение сверху вниз.

При обнаружении пересечения создаётся маркер. Для уведомления о найденных маркерах используется механизм событий C#.

Основные классы:

| Класс | Назначение |
|---|---|
| `ThresholdAnalyzer` | Выполняет поиск пересечений заданного порога |
| `CrossingDirection` | Определяет направление пересечения |
| `SignalMarker` | Хранит индекс отсчёта и направление пересечения |
| `SignalAnalysisResult` | Содержит исходный сигнал и список найденных маркеров |
| `MarkerDetectedEventArgs` | Передаёт информацию о найденном маркере, времени и значении сигнала |

Время пересечения определяется по индексу отсчёта и частоте дискретизации. Значение сигнала берётся из соответствующего отсчёта.

Анализатор не зависит от графических компонентов. На его событие `MarkerDetected` могут подписываться различные обработчики, не изменяя сам алгоритм анализа.

### Подписчики событий

Для демонстрации расширяемости механизма событий реализованы отдельные классы-подписчики:

| Класс | Назначение |
|---|---|
| `MarkerCounter` | Подсчитывает количество пересечений вверх и вниз |
| `MarkerIntervalAnalyzer` | Определяет минимальный и максимальный интервалы между соседними пересечениями |

Подписчики обрабатывают маркеры по мере их обнаружения и могут сбрасывать накопленные результаты с помощью метода `Reset()`.

## Тестирование

Для проверки корректности работы библиотеки используется проект `SignalProcessing.Core.Tests` на базе xUnit.

Тесты проверяют:

- создание и валидацию сигналов;
- работу генераторов и фабрики;
- корректность фильтрации;
- операции над сигналами;
- изменение частоты дискретизации;
- работу циклического буфера;
- обнаружение пересечений порога;
- правильность направления и времени маркеров;
- работу событий и подписчиков;
- обработку некорректных входных данных;
- сброс состояния компонентов.

## Сборка и запуск тестов

Для работы с проектом требуется Visual Studio с поддержкой .NET Framework 4.8.

1. Откройте `SignalProcessing.Core.sln`.
2. Выполните **Build → Build Solution**.
3. Откройте **Test → Test Explorer**.
4. Нажмите **Run All Tests**.

Необходимые пакеты NuGet для тестирования подключаются через конфигурацию проекта.


`..\signals-core\SignalProcessing.Core\`
